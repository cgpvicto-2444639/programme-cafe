Pour pouvoir exécuter mon programme, vous devez avoir d'installé la version 3.15.2 de Python sur votre ordinateur.
Installation: https://www.python.org/downloads/release/python-3152/

Lorsque vous avez bien installé Python, vous avez simplement à ouvrir le fichier dans VSCode, ouvrir la console et d'exécuter cette commande:
python cafe.py

ou

Cliquer sur l'icone en triangle pour exécuter le programme automatiquement.
